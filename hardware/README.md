# Hardware preview

The [controller signal map](rp2350-pinmap.csv) documents the intended MAIN
and AUX connections. The [QuickPurge STL](mechanical/quickpurge/) is an
original Sidecar design available under CC BY-NC 4.0 for the model file.

The printable Sidecar parts derived from BoxTurtle and the electronics
design are being prepared for a subsequent source release. Pin assignments,
power routing, fabrication details, mechanical fit, and assembly instructions
need review before others build hardware from this preview.
